## Concept

The concept is called **Aetherial Renaissance**.

The landing page presents Techfest as a place where ideas, engineering, creativity and imagination come together. The visual design uses a futuristic 2D system based on:

- Technical grids.
- Orbit lines.
- Editorial typography.
- Orange, yellow and dark navy colours.
- Scroll-based reveal animations.
- Interactive event cards.
- A live event countdown.

## Features

- Responsive landing page.
- Hero section with futuristic 2D graphics.
- Scroll progress indicator.
- Mobile navigation menu.
- Scroll reveal animations.
- Event category cards.
- Featured competition section.
- Workshop section.
- Live countdown to 16 December 2026.
- Responsive layout for mobile, tablet and desktop.
- Reduced-motion support.
- No 3D assets or external JavaScript libraries.
